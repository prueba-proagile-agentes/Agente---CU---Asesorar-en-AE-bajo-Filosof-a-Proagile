# Plantillas del paquete de Assessment

Estas plantillas describen el contenido mínimo de los ocho entregables. Para los
formatos binarios, el archivo Markdown define hojas, columnas o secciones que el
agente debe materializar en `.xlsx`, `.docx` o `.pdf`.

No completar campos desconocidos ni crear conclusiones de ejemplo. Usar
`Pendiente`, `No verificado` o una limitación explícita según corresponda.
