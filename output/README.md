# Entregables finales

Versionar solo contenido revisable y trazable; no guardar notas sueltas ni
temporales. Registrar fecha, inputs utilizados, versiones de skills, supuestos,
limitaciones y validaciones realizadas. El manifiesto y el checklist son los
documentos de control auditables del paquete y se actualizan durante su ciclo.

Los paquetes de Assessment se guardan en `output/assessments/<id>/`, donde el
identificador usa el formato neutral `ASMT-AAAA-NNN`. No usar nombres de clientes
en rutas ni copiar evidencias originales salvo autorización y necesidad
explícitas.

El paquete estándar contiene el estado y los entregables:

- `assessment.md`: manifiesto, rama, etapa, versión y estado general.
- `checklist.md`: avance, evidencias, bloqueos y controles de cierre.
